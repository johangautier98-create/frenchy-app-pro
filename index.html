📖 Guide d'utilisation — Frenchy Leurres Étiquettes Pro
1

Recevoir une commande

Quand vous recevez une commande (email, PDF, photo), allez sur l'onglet Commande.

  • Pour un PDF : cliquez sur la zone import et sélectionnez le PDF — le texte sera extrait automatiquement
  • Pour une photo : importez l'image, lisez-la et tapez la commande dans le champ texte
  • Pour un email : copiez-collez le texte directement dans le champ
💡 Vous pouvez écrire la commande en langage naturel : "Mistik Shad Vert 9cm x6" ou "6 Frenchy Shiner Bleu Flash 9cm"
2

Analyser et valider

Cliquez sur Analyser la commande. L'application va détecter automatiquement chaque produit et sa quantité.

  • 🟢 Vert = produit reconnu dans le catalogue
  • 🔴 Rouge = produit non reconnu — ajout manuel possible

Ajustez les quantités si besoin, puis cliquez Tout ajouter à la file d'impression.

3

Ajout manuel (produit inconnu)

Si un produit n'est pas reconnu, cliquez Ajouter manuellement. Entrez le nom, la couleur, la taille et le numéro EAN-13. Le code-barres sera généré automatiquement.

💡 Vous pouvez aussi ajouter directement depuis l'onglet Catalogue en cliquant sur un produit.
4

File d'impression

Dans l'onglet Impression, vous verrez deux files :

  • Rouleau rectangulaire (40×30mm) : tous les produits avec code-barres EAN-13
  • Rouleau rond (15mm) : uniquement les Rougets (taille + grammage)

Utilisez les boutons ×1 ×4 ×6 ×10 ×20 ×50 pour ajuster les quantités rapidement.

5

Imprimer avec la Xprinter XP-365B

Cliquez sur le bouton Imprimer. Une fenêtre Windows s'ouvre :

  • Sélectionnez Xprinter XP-365B
  • Format du papier → 40×30mm (ou votre format)
  • Marges → Aucune
  • Mise à l'échelle → Taille réelle
💡 Ces réglages sont mémorisés par Windows. Après la première configuration, un simple clic suffit !
6

Utiliser sur téléphone ou tablette

Ouvrez ce fichier depuis n'importe quel navigateur sur votre réseau Wi-Fi. L'application s'adapte automatiquement à l'écran.

💡 Sur téléphone, vous pouvez photographier une commande manuscrite, importer la photo et taper la commande en lisant l'image.
